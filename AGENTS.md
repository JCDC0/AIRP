# AGENTS.md

Entry point for coding agents (Codex, Cursor, Copilot, Zed, and others that read
`AGENTS.md`). The canonical agent guide lives in `docs/agents/`.

Read **[docs/agents/ARCHITECTURE.md](docs/agents/ARCHITECTURE.md)** before making
any change. It covers architecture, build and test commands, coding conventions,
versioning rules, and the provider checklist.

Version history: **[docs/agents/CHANGELOG.md](docs/agents/CHANGELOG.md)**
Open defects: **[docs/audits/](docs/audits/)**

Quick reference:

- Install: `flutter pub get`
- Run: `flutter run`
- Test: `flutter test` (140 tests, must stay green)
- Analyze: `flutter analyze` (clean, must stay clean)

Always run `flutter analyze` and `flutter test` before committing.

Do not edit this file for content changes; edit `docs/agents/ARCHITECTURE.md`.
