| 0.7.28 | K | **Atmospheric effects rewrite + CRT background.** The old overlay built one `LoopAnimationBuilder` and one full-screen `CustomPaint` *per particle* (fireflies nested a second controller inside the first), so defaults meant ~80 animation controllers and ~80 compositor layers per frame, each doing a `MaskFilter.blur` gaussian. Replaced with one `Ticker` and one `CustomPaint` for all effects; glowing particles render in a single `Canvas.drawAtlas` call against a sprite sheet rendered once at startup. The ticker stops entirely when no effect is enabled. Motion is now closed-form in `t` (resolution independent, resumable, unit-testable). **Motes:** depth-based parallax, two-term sine wander instead of a straight A-to-B lerp, twinkle. **Rain:** one shared wind slant for the field (was derived per drop from its own length, so drops crossed at different angles), streak length proportional to fall speed, depth layering, visible opacity. **Fireflies:** no longer a recoloured mote. Four-term incommensurate-sine flight, discrete blink envelope (fast rise, brief hold, decay, then a long dark interval that is the majority of the cycle), small bright core inside a wide halo, bioluminescent yellow-green hue band. **New `CRT Screen` effect:** `shaders/crt.frag` fragment shader applying barrel/fisheye distortion, chromatic aberration, rolling scanlines, aperture grille and vignette to the background image only, with a `CRT Intensity` slider. Text is deliberately excluded so glyphs stay flat and crisp. Falls back to a plain `BoxFit.cover` image if the platform cannot compile the shader. | done |
| 0.7.28.1 | K | **CRT reworked around fuzz; effect sliders are real counts.** 0.7.28 shipped the CRT as a background-only barrel warp, so raising intensity just deepened a fisheye wallpaper while text stayed untouched. Rewritten: `CrtScreen` wraps the whole chat surface in a `SnapshotWidget`, rasterises it, and runs background, particles and text through `shaders/crt.frag` together. The shader now leads with analog artifacts (seven-tap horizontal smear for lost bandwidth, bloom bleed from bright areas, colour separation growing toward the edges, rolling scanlines, aperture grille, per-frame grain, stronger vignette); barrel distortion is capped at `0.045` so curvature is felt, not seen. Replaces `CrtBackground`. **Slider fix:** each effect now draws a prefix of a fixed, fixed-seed pool instead of regenerating the whole field on every change, which had made the slider behave like a reseed. Sliders are percentages of `kMaxMotes` / `kMaxRainDrops` / `kMaxFireflies`, so 50% always draws the same first half and raising the value only adds particles. Stored raw counts migrate once to the percentage scale via `VfxProvider.percentFromLegacy`. **Motes:** cubic-weighted radius distribution spanning minute specks to markedly larger out-of-focus ones, with big specks held dimmer; twinkle unchanged. | done |
| 0.7.28.2 | K | **Fix frozen chat under CRT; split scanline and fisheye controls.** 0.7.28.1 used `SnapshotWidget`, which caches its raster: its painter's `notifyListeners` repaints "re-using the same raster" by design, and children behind a `RepaintBoundary` (the message list and effects overlay both are) never mark it dirty. The chat therefore froze at the first frame while scanlines kept rolling. Replaced with a `RenderProxyBox` (`_RenderCrtEffect`) that paints the child into a detached `OffsetLayer` and `toImageSync`es it **every** frame, mirroring the framework's own `_paintAndDetachToImage`. Content is live again; the cost is a full-surface rasterise per frame, inherent to a live post-process. Falls back to painting the child untreated when a subtree cannot be rasterised. **New controls:** `CRT Scanlines` slider drives scanline and aperture-grille visibility from its own uniform, independent of master intensity, so at 0 the raster structure disappears and only the signal artifacts (smear, bloom, chromatic aberration, grain) remain. `CRT Fisheye` switch gates the barrel warp entirely; off by default, and when off the sampling grid is untouched at any intensity. Both persist and round-trip through config packs. | done |

## Key decisions

Preserve these across context compaction.

*   **Reasoning:** persist in session JSON for redisplay; strip the thinking tag
    ONLY from the outbound LLM payload, never from displayed or stored text. The
    per-bubble "Show Thought Process" chip stays; no new input-area control.
*   **Summarize branching:** the new conversation is [narrative summary] + [voice
    samples] + [last N assistant/user pairs]. The slider counts assistant turns and
    pairs are anchored on the assistant side. The original conversation is untouched.
*   **Config Packs:** capture ALL settings-drawer state except conversations and API
    keys. SillyTavern support is IMPORT-ONLY. The old per-rule store was discarded
    with no migration.
*   **Web search:** no Smart/Eager modes. Tell the LLM it has the tool with the
    configured limits and let it decide. Reasoning must remain visible during tool
    calls.
*   **Lore:** history scanning was removed deliberately in `0.6.11.1` and is not
    coming back without an explicit decision. Current-input recognition is the whole
    feature. See the lore section in `ARCHITECTURE.md`.
